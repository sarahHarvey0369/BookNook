# BookNook

A full-stack personal library management application.

## Technology Stack

- Angular / TypeScript
- C# / ASP.NET Core Web API
- PostgreSQL
- Docker / Docker Compose
- WSL2 / Ubuntu

## Architecture

Microservices-based application with an Angular client,
ASP.NET Core API gateway, and independently managed services.

## Development Environment

Windows + WSL2 Ubuntu + Docker Desktop.
